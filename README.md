# bitrix-personal-tasks

Google Apps Script для выгрузки задач из **Bitrix24 (Scrum)** в **Google Sheets**.

## Что здесь есть

| Файл | Назначение |
|---|---|
| [`BitrixTasksToSheets.gs`](BitrixTasksToSheets.gs) | Основной скрипт личных задач: меню «Bitrix» — выгрузка ваших задач, ретро, планирование, «сегодня: время/выполнено». |
| [`BitrixTimeByPeriodExport.gs`](BitrixTimeByPeriodExport.gs) | Отдельный файл к основному скрипту: кнопка «Учёт времени за период» — весь ваш учёт времени за произвольный срок (по строке на каждую запись). |
| [`BitrixMyTasksExport.gs`](BitrixMyTasksExport.gs) | Отдельный файл к основному скрипту: кнопка «Все мои задачи (без спринтов)» — все задачи, где вы исполнитель, без обращения к скраму. |
| [`BitrixSprintTasksExport.gs`](BitrixSprintTasksExport.gs) | Скрипт для Google Таблиц: меню «Спринт» с выгрузкой задач одного спринта и своих отложенных задач. |
| [`docs/BitrixTimeByPeriodExport.md`](docs/BitrixTimeByPeriodExport.md) | Как работает выгрузка учёта времени за период: формат срока, что берётся, настройки, отладка. |
| [`docs/BitrixMyTasksExport.md`](docs/BitrixMyTasksExport.md) | Как работает выгрузка всех моих задач: колонки, настройки, отладка. |
| [`docs/BitrixSprintTasksExport.md`](docs/BitrixSprintTasksExport.md) | Подробное описание: как работает скрипт, все функции, используемые методы Bitrix REST, настройки и отладка. |

## Коротко о скрипте

`BitrixSprintTasksExport.gs` добавляет в таблицу меню **«Спринт»**:

- **Выгрузить задачи спринта** — все задачи одного названного спринта (по умолчанию
  `Спринт июль 2`) с планом/фактом времени, стори-поинтами, признаком «в срок?» и
  прямой ссылкой на задачу. Лист `Задачи спринта`.
- **Выгрузить мои отложенные задачи** — все задачи, где вы исполнитель и статус
  «Отложена». Лист `Отложенные`.
- **Выгрузить задачи за период** — детализация по учёту времени за выбранный период
  (по строке на каждую запись учёта: дата/время, длительность, комментарий, задача,
  проект и, если задача в спринте, id и название спринта). Лист `Учёт времени`.
- **Указать вебхук** — сохранить входящий вебхук портала Bitrix24 (право `task`).

## Учёт времени за период

`BitrixTimeByPeriodExport.gs` — отдельный файл, который добавляет в основной
скрипт (`BitrixTasksToSheets.gs`) пункт меню **«Учёт времени за период»**.
Он выгружает на лист **`Учёт времени за период`** ВЕСЬ ваш учёт времени за
выбранный срок — по одной строке на каждую запись учёта (дата/время,
длительность, комментарий, задача, проект, ссылка) плюс итог по времени.

Берутся записи, где время учитывали вы (`USER_ID` = вы), по задачам, где вы
исполнитель (`RESPONSIBLE_ID` = вы; чтобы включить и чужие задачи, где вы вели
время, — `TP_ONLY_MY_TASKS = false` вверху файла).

**Срок задаётся одной строкой** в формате `дд.мм.гггг-дд.мм.гггг`, например
`07.07.2026-15.07.2026`.

Подключение: вставьте `BitrixTimeByPeriodExport.gs` в тот же проект Apps Script,
где лежит `BitrixTasksToSheets.gs`, и добавьте в его `onOpen` строку
`.addItem('Учёт времени за период', 'tpExportTimeByPeriod')` (в этом репозитории
она уже добавлена). Вебхук — общий, повторно вводить не нужно.

## Все мои задачи (без спринтов)

`BitrixMyTasksExport.gs` — отдельный файл, который добавляет в основной скрипт
пункт меню **«Все мои задачи (без спринтов)»**. Он выгружает на лист
**`Мои задачи`** все задачи, где вы исполнитель, — из скрам-групп, обычных
проектов и без проекта. К скраму скрипт не обращается вообще, поэтому спринты
ни на что не влияют. В заголовке листа — сводка: всего / в работе / завершено /
просрочено.

Подключение: вставьте `BitrixMyTasksExport.gs` в тот же проект Apps Script, где
лежит `BitrixTasksToSheets.gs`, и добавьте в его `onOpen` строку
`.addItem('Все мои задачи (без спринтов)', 'mtExportMyTasks')` (в этом
репозитории она уже добавлена). Вебхук — общий, повторно вводить не нужно.

## Быстрый старт

1. Google-таблица → **Расширения → Apps Script** → вставьте `BitrixSprintTasksExport.gs`.
2. Сохраните, обновите вкладку таблицы — появится меню **«Спринт»**.
3. **«Спринт» → «Указать вебхук»**, вставьте URL вида
   `https://ВАШ-ПОРТАЛ.bitrix24.ru/rest/123/xxxxxxxxxx/` (Bitrix: Разработчикам → Другое
   → Входящий вебхук, право `task`).
4. При необходимости поменяйте `SE_SPRINT_NAME` вверху файла на нужное имя спринта.
5. **«Спринт» → «Выгрузить задачи спринта»**.

Полная инструкция и разбор кода — в [docs/BitrixSprintTasksExport.md](docs/BitrixSprintTasksExport.md).
